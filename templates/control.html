Simulink: Adding the Brain

On the last page, our virtual machine bounced around too much. Now, it's time to add the "PID Brain" block to our Lego set so it can control itself!

Adding the PID Block

To fix the bouncing, we just drop a new Lego block into our Simulink model: the PID Controller Block. We put it right between the Push (the input) and the Machine.

The Magic Loop (Feedback)

Notice the line going from the very end, back to the beginning? That's called a Feedback Loop. It's how the Brain looks at the screen to see where the piston is, realizes it made a mistake, and adjusts the air pressure for the next second. It’s exactly like driving a car and watching the road!

Upgrading to State Space

Want to be even fancier? We can swap out the simple Machine block for a State-Space Block (the one that acts like an engine dashboard). This gives the computer even more control.

PID vs. State Space

Let's put them in a race! The red line is the State Space (Dashboard), and the blue line is the PID (Speedometer).

Analysis: Both Brains work! But notice how the State Space (red line) is slightly smoother. Because it looks at everything at once, it never guesses wrong.
